## Frontend Components

### FC-01: Search Module
- **목적**: 약물 검색 UI 및 검색 결과 표시
- **책임**:
  - 검색 입력 폼 (자동완성 포함)
  - 검색 결과 목록 렌더링
  - 약물 상세 정보 표시
  - 검색 결과에서 약상자 추가 액션 제공

### FC-02: Medicine Box Module
- **목적**: 사용자의 '내 약상자' 관리 UI
- **책임**:
  - 약상자 목록 표시
  - 약물 추가/삭제 인터랙션
  - 약상자 기반 상성 분석 트리거
  - 빈 상태/로딩 상태 처리

### FC-03: Analysis Report Module
- **목적**: 약-음식 상성 분석 결과 시각화
- **책임**:
  - 위험도별 (주의/경고/금기) 색상 구분 표시
  - 피해야 할 음식 목록 렌더링
  - 상호작용 요약 표시
  - 상세 가이드 링크 (Post-MVP)

### FC-04: Auth UI Module
- **목적**: 로그인/회원가입/계정 관리 UI
- **책임**:
  - 이메일/비밀번호 로그인 폼
  - 소셜 로그인 버튼 (Google, Kakao)
  - 회원가입 폼
  - 비밀번호 재설정 플로우

### FC-05: Layout & Navigation
- **목적**: 앱 전체 레이아웃, 네비게이션, 다국어 전환
- **책임**:
  - 글로벌 레이아웃 (헤더, 푸터, 사이드바)
  - 네비게이션 메뉴
  - 언어 전환 (한국어/영어)
  - 반응형 디자인 처리

## Backend Components

### BC-01: Drug Module
- **목적**: 약물 데이터 관리 및 검색 기능 제공
- **책임**:
  - 약물 검색 (제품명/성분명)
  - 약물 상세 정보 조회
  - 약물 목록 페이지네이션
  - 자동완성 데이터 제공

### BC-02: Medicine Box Module
- **목적**: 사용자별 약상자 CRUD 관리
- **책임**:
  - 약상자에 약물 추가
  - 약상자에서 약물 제거
  - 사용자별 약상자 조회
  - 약상자 약물 개수 제한 관리

### BC-03: Interaction Module
- **목적**: 약-음식 상성 분석 엔진
- **책임**:
  - 약물 성분 기반 음식 상호작용 매칭
  - 위험도(Risk Level) 3단계 분류
  - 상호작용 상세 정보 제공
  - 복수 약물 동시 분석 지원

### BC-04: Auth Module
- **목적**: 인증/인가 처리
- **책임**:
  - 이메일/비밀번호 인증
  - OAuth 2.0 (Google, Kakao) 처리
  - JWT 토큰 발급/검증/갱신
  - 비밀번호 재설정 토큰 관리

### BC-05: User Module
- **목적**: 사용자 프로필 관리
- **책임**:
  - 사용자 정보 CRUD
  - 계정 설정 관리
  - 사용자 언어 설정 저장

## Data Layer Components

### DC-01: Drug Repository
- **목적**: 약물/식품 데이터 영속화
- **테이블**: drugs, drug_ingredients, foods, food_nutrients

### DC-02: Interaction Repository
- **목적**: 약-음식 상호작용 데이터 관리
- **테이블**: interactions (drug_ingredient_id, food_id, risk_level, description)

### DC-03: User Repository
- **목적**: 사용자 및 인증 데이터 관리
- **테이블**: users, accounts, sessions

### DC-04: Medicine Box Repository
- **목적**: 약상자 데이터 관리
- **테이블**: medicine_boxes, medicine_box_items
