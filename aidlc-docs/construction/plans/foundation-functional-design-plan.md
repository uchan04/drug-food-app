### Q-FD1: 약물 데이터 구조

A) 제품 → 성분 2단계 (단순: 제품에 성분 목록 매핑)  
B) 제품 → 성분 → 성분 카테고리 3단계 (성분을 약리 분류별로 그룹핑)

### Q-FD2: 상호작용 데이터 다국어 처리

상호작용 설명(reason, sideEffects) 텍스트의 다국어 저장 방식은?

A) 별도 컬럼 (reason_ko, reason_en) — 단순하고 명시적

C) 별도 번역 테이블 (translations) — 가장 확장성 좋음, 복잡도 높음  
D) 선호 없음 — AI-DLC가 추천  
X) 기타 (아래에 직접 기재)
