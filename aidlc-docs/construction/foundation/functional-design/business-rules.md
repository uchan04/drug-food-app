# Business Rules - Unit 1: Foundation

## 데이터 유효성 규칙

### BR-01: User 엔티티

| 규칙 ID | 규칙 | 제약 조건 |
|---------|------|-----------|
| BR-01-01 | 이메일 형식 유효성 | RFC 5322 준수, 최대 255자 |
| BR-01-02 | 비밀번호 최소 강도 | 최소 8자, 영문+숫자 조합 |
| BR-01-03 | 이메일 고유성 | 동일 이메일 중복 가입 불가 |
| BR-01-04 | OAuth 사용자 비밀번호 | provider가 google/kakao면 password_hash는 null |
| BR-01-05 | 이름 길이 | 1~50자 |
| BR-01-06 | 언어 설정 | 'ko' 또는 'en'만 허용 |

### BR-02: Drug 엔티티

| 규칙 ID | 규칙 | 제약 조건 |
|---------|------|-----------|
| BR-02-01 | 이름 필수 | name_ko, name_en 모두 비어있으면 안 됨 |
| BR-02-02 | 카테고리 필수 | category는 빈 문자열 불가 |
| BR-02-03 | 성분 최소 1개 | 약물은 최소 1개 이상의 성분을 가져야 함 |

### BR-03: Interaction 엔티티

| 규칙 ID | 규칙 | 제약 조건 |
|---------|------|-----------|
| BR-03-01 | 위험도 범위 | risk_level은 'caution', 'warning', 'contraindicated' 중 하나 |
| BR-03-02 | 고유 매핑 | 동일 (ingredient_id, food_id) 조합은 하나의 상호작용만 존재 |
| BR-03-03 | 시간 간격 범위 | time_gap_hours는 null 또는 1~72 범위 |
| BR-03-04 | 설명 필수 | reason_ko, reason_en 최소 10자 이상 |

### BR-04: MedicineBox 엔티티

| 규칙 ID | 규칙 | 제약 조건 |
|---------|------|-----------|
| BR-04-01 | 중복 방지 | 동일 사용자가 같은 약물을 중복 추가 불가 |
| BR-04-02 | 최대 개수 제한 | 한 사용자의 약상자는 최대 20개 약물 |
| BR-04-03 | 유효한 약물만 | drug_id는 실존하는 Drug를 참조해야 함 |
| BR-04-04 | 인증 필수 | 약상자 조작은 인증된 사용자만 가능 |

## 데이터 무결성 규칙

### CASCADE 규칙

| 부모 엔티티 | 자식 엔티티 | 삭제 시 동작 |
|------------|------------|-------------|
| User | MedicineBox | CASCADE (사용자 삭제 시 약상자 삭제) |
| Drug | DrugIngredient | CASCADE (약물 삭제 시 성분 삭제) |
| Drug | MedicineBox | CASCADE (약물 삭제 시 약상자에서 제거) |
| DrugIngredient | Interaction | CASCADE (성분 삭제 시 상호작용 삭제) |
| Food | Interaction | CASCADE (음식 삭제 시 상호작용 삭제) |

## 검색 규칙

### BR-05: 검색 로직

| 규칙 ID | 규칙 | 상세 |
|---------|------|------|
| BR-05-01 | 최소 검색어 길이 | 1자 이상 (자동완성은 2자 이상) |
| BR-05-02 | 최대 검색어 길이 | 100자 이하 |
| BR-05-03 | 검색 대상 필드 | name_ko, name_en, ingredient name_ko, ingredient name_en |
| BR-05-04 | 정렬 순서 | 유사도(similarity) 내림차순 |
| BR-05-05 | 페이지네이션 | 기본 limit: 20, 최대 limit: 100 |
| BR-05-06 | 자동완성 제한 | 최대 10개 결과 |

## 시드 데이터 규칙

### BR-06: 초기 데이터

| 규칙 ID | 규칙 | 상세 |
|---------|------|------|
| BR-06-01 | 최소 약물 수 | 시드 데이터에 최소 6개 카테고리, 카테고리당 2-3개 약물 |
| BR-06-02 | 최소 음식 수 | 시드 데이터에 최소 15개 음식 |
| BR-06-03 | 최소 상호작용 수 | 시드 데이터에 최소 20개 상호작용 |
| BR-06-04 | 다국어 완전성 | 모든 시드 데이터는 ko/en 모두 제공 |
| BR-06-05 | 위험도 분포 | 3단계 위험도가 모두 시드 데이터에 포함 |

## RiskLevel 비즈니스 정의

| Level | 한국어 | 영어 | 의미 | UI 색상 |
|-------|--------|------|------|---------|
| caution | 주의 | Caution | 가벼운 상호작용, 인지하면 됨 | 노랑 (#FFC107) |
| warning | 경고 | Warning | 의미 있는 상호작용, 시간 간격 권장 | 주황 (#FF9800) |
| contraindicated | 금기 | Contraindicated | 함께 섭취 금지, 심각한 부작용 가능 | 빨강 (#F44336) |
